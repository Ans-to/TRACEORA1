# One Spark — stickman edition

An original 15-second stickman story rendered with Geneva v1.6.0. The three acts are editable HTML/CSS scenes with a JSON timeline and a procedurally generated score.

Run `geneva render geneva-stickman/sample.json -o geneva-stickman/stickman.mp4` or download the committed MP4. Fonts are Inter under the bundled OFL license.
